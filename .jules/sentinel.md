## 2024-05-16 - Prevent Predictable File Names in Uploads\n**Vulnerability:** Weak random number generator (`Math.random()`) used for file names, which could lead to predictable URLs or file collisions.\n**Learning:** `Math.random()` is not cryptographically secure and should not be used when generating unique IDs for user-uploaded content in public-facing storage.\n**Prevention:** Use `crypto.randomUUID()` to generate collision-resistant and secure unique identifiers.
