## 2024-05-24 - Insecure Random Number Generation for File Names\n**Vulnerability:** Weak random number generation (`Math.random()`) was used to generate parts of file names for uploaded videos.\n**Learning:** This existed because `Math.random()` is convenient, but it is not cryptographically secure, meaning generated values could potentially be predicted.\n**Prevention:** Always use cryptographically secure methods like `crypto.randomUUID()` when generating unique identifiers, tokens, or file names where unpredictability is important for security.
